
# Interactive Background Color Changer

A simple and responsive web project that changes the page background color with a single click. Built with HTML, CSS, and vanilla JavaScript.

## Features

- Change the background to purple, blue, red, green, yellow, or teal
- Random color button that picks a different color from the list
- Smooth background transition effect
- Responsive layout that works on desktop, tablet, and mobile
- Hover and click animations on the buttons

## Technologies Used

- HTML5
- CSS3 (Flexbox, `clamp()`, media queries, transitions)
- JavaScript (DOM manipulation, event listeners)
